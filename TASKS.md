# Launch Checklist

> only *click-to-toggle* inside a **GitHub Issue or Pull Request** body — not in a
> regular repo file view, where you'd need to edit the file and commit the change.
> If you want true one-click checking on GitHub itself, copy this file's contents into
> a new Issue titled "Launch Checklist" and check items off there; GitHub will also
> show you a live progress bar on the Issues list automatically.

> [`docs/launch-checklist.html`](./docs/launch-checklist.html) — open it directly in a

### Enabling GitHub Pages for the interactive version

Repo → Settings → Pages → Source: deploy from the `main` branch, `/docs` folder →
Save. GitHub will publish `docs/launch-checklist.html` at a public URL. One caveat:
the auto-save feature in that file depends on a storage API only available inside
Claude's own artifact environment — on GitHub Pages, checking a box will still work
visually in that session, but won't persist after a page refresh. Treat the GitHub
Pages version as a shareable read-only view, and keep using the version inside this
Claude conversation (or re-download it here) as your actual saved, persistent copy.
